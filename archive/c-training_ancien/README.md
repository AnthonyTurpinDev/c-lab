# C Training

Parcours d'entrainement progressif en C, organise du niveau 0 aux simulations
de Piscine.

Chaque chapitre contient les fichiers d'exercices directement dans son dossier.
Compiler un exercice avec :

```text
gcc -Wall -Wextra -Werror c-training/00_basics/ex01_hello.c -o build/ex01_hello.exe
```

Les exercices sont des squelettes de travail : completer le code, tester les
cas limites et noter les erreurs dans `notes.md` avant de passer au suivant.

## Parcours

`00_basics` -> `01_variables` -> `02_operators` -> `03_conditions` ->
`04_switch` -> `05_while` -> `06_for` -> `07_functions` -> `08_recursion` ->
`09_arrays` -> `10_strings` -> `11_pointers` -> `12_pointer_arrays` ->
`13_malloc` -> `14_argc_argv` -> `15_structures` -> `16_structures_pointers` ->
`17_files` -> `18_debugging` -> `19_mixed` -> `20_mini_projects` ->
`21_pool_simulations`.

Les chapitres 19 a 21 combinent les notions precedentes et se travaillent sans
correction, avec une limite de temps.
