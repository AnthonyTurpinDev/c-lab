# Archive

Anciennes structures et contenus conservés pour référence.

## Exercices anciens

Les exercices C issus des premières sessions sont regroupés dans
`exercices_anciens/`. Ils sont conservés comme référence historique et ne
font pas partie du parcours pédagogique actif.

## c-training_ancien/

Ancienne organisation par jours (jour-1, jour-2, jour-3). Convertir progressivement vers la nouvelle structure pédagogique.

Les nouveaux exercices doivent suivre l'organisation dans la racine du projet:
- 00_fondations/
- 01_donnees/
- 02_memoire/
- etc.
