1. **01_syntaxe_et_compilation/** — Hello World, flags de compilation, Makefile
2. **02_types_variables/** — int, char, float, double, printf, scanf
3. **03_conditions/** — if/else, opérateurs de comparaison, switch
4. **04_boucles/** — while, for, boucles imbriquées
5. **05_fonctions/** — déclaration, récursivité simple, passage d'arguments

---

## Conseils

- Compile **toujours** avec `-Wall -Wextra -Werror`
- Teste les cas limites (0, valeurs négatives, etc.)
- Fais un commit Git par séance
- Si une erreur se répète, note-la dans `docs/erreurs_frequentes.md`
